# Evidence capture (Phase 0)

> **Md-এর জন্য সংক্ষেপে:** নিজের UDC account দিয়ে prottoyon-এ লগইন করে প্রতিটি সেবার ফর্ম খুলুন, একটি **পরীক্ষামূলক (synthetic) নাগরিক** দিয়ে। `prottoyon-forms/` ফোল্ডারের প্রতিটি ফাইলে আগে থেকে Astra-র ঘরগুলো লেখা আছে; প্রতিটি সারিতে মিলে গেলে ✅, না মিললে সংশোধন লিখুন। কোনো আসল নাগরিকের তথ্য, ছবি বা সনদ এখানে রাখবেন না।

Astra builds **functional** parity with the Prottoyon reference system: a user who knows Prottoyon can do the same things in Astra, the same way. Phase 0 collects the facts that are still unverified, so later phases build from evidence instead of guesses.

**Who does what.** Claude does not sign in to Prottoyon. Md (the owner) captures from his own account; Claude prepares the templates, pre-fills what Astra already knows, and builds from the completed files.

## Capture rules

1. **No real people's data.** Use only the synthetic citizen. Do not record, photograph or upload any real citizen's name, NID, birth registration, mobile, address, photo or certificate. If a screen shows other people's records (lists, queues), do not capture it; describe the columns and actions in words instead.
2. **Record facts, not artwork.** Field labels, option lists, required/optional, limits and the order of steps are functional facts and should be copied exactly (`options verbatim`). Do **not** copy logos, emblems, certificate artwork, page design, help text, FAQ answers or other prose; Astra writes its own.
3. **Do not submit real applications or payments.** Stop at the last screen before a payment or a final submission unless the reference system clearly allows a free test. Never pay for a test.
4. **Mark what you saw.** In each row, mark ✅ when Astra matches what you saw, write the correction when it does not, and `?` when you could not see it. Add rows for fields Astra does not have.
5. **Screenshots** are optional and must show only the synthetic citizen. Keep them out of the repository unless they contain no personal data at all.

## What Phase 0 unblocks

Phase 4 (services and forms, schema v4+) and Phase 6 (office workflow) start only from completed capture files. Services whose files stay incomplete keep their current schema and are flagged, not guessed.

Design tokens (guide item 0.4) are **not** captured: Astra keeps its own colours, fonts and artwork so that its pages and certificates cannot be mistaken for the reference system's. Layout and workflow parity is still in scope.
